InmobilIA Pro REST API v2

Documentación de la API pública. Genera tu API key en /api-keys.

Autenticación

Authorization: Bearer ipro_TU_TOKEN

Endpoints

GET /api/v2/properties

Lista propiedades. Query: limit, tipo

POST /api/v2/leads

Crea un lead. Body: {"nombre":"...","email":"...","telefono":"..."}

GET /api/v2/stats

Estadísticas de la cuenta.

GET /api/v2/openapi.json

Especificación OpenAPI 3.0 completa.

Ejemplo

curl -X POST https://inmobiliapro.es/api/v2/leads \
  -H "Authorization: Bearer ipro_xxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"nombre":"Juan García","email":"juan@example.com","telefono":"600000000"}'
